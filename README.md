# ApplyPanda

ApplyPanda is a web product layer built on top of the open-source
[`santifer/career-ops`](https://github.com/santifer/career-ops) project.

## What This Repo Is

This repository focuses on:

- Next.js web UI
- Hosted backend/API routes
- Supabase auth/data integration
- Multi-tenant isolation controls
- Vercel deployment flow

In short: this is the SaaS-style dashboard + backend work on top of the
career-ops foundation.

## Local Setup

For the core local pipeline setup and usage (career-ops modes, scanner,
evaluations, and related workflow), use the upstream documentation:

- Upstream repo: <https://github.com/santifer/career-ops>
